# Asset inventory

| Files | Source and use |
| --- | --- |
| `velvet-envelope.webp`, `velvet-envelope-mobile.webp` | Original generated burgundy stationery with embossed botanicals, optimized for the desktop and mobile gate. |
| `cover.webp` | Original generated botanical and gold-foil artwork for the closing scene and the social composition. |
| `curtains.webp` | Original generated champagne silk, animated as independently moving halves. |
| `ganesha.webp`, `mandapam.webp`, `dinner.webp`, `flowers.webp` | Original generated devotional illustration, ceremonial decor, hospitality still life, and botanical artwork. The illustrated mandapam is decor for the ceremony scene. |

| `mark.svg` and inline SVG | Original geometric monogram, heart, flourishes, and navigation icons. |
| `theme.mp3` | Original 33-second instrumental composition synthesized for this project. No samples or commercial recordings. The NumPy script in `scripts/compose_theme.py` renders the WAV master, which can be encoded to MP3 with LAME or FFmpeg. |
| `kalyanam-kamaniyam.mp3` | MP3 supplied by the user and used as the invitation’s background track. |
| Cormorant Garamond, DM Sans, Noto Sans Telugu | Self-hosted Fontsource distributions under the SIL Open Font License. License texts are shipped in `public/licenses/`. |
| Reel and printed card | Supplied references for choreography and factual verification. The site ships original artwork and omits the reference media. |

The current chapters use `welcome.webp` for the illustrated opening doors, `wedding-ritual.webp` for the ceremonial scene, `wedding-serving.webp` for the dinner scene, and `village.webp` for a coastal Andhra-inspired illustration. These are original generated illustrations. The wedding figures are illustrative and the village scene is an artistic impression.

The family section uses two original illustrated family scenes, and the closing section uses two original namaste illustrations. The family scenes are artistic depictions. Instrument Serif is self-hosted under the SIL Open Font License.

Cinzel is self-hosted for the English elders’ blessing heading under the SIL Open Font License.
